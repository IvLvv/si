# Своя игра

React + Vite. Без бэкенда и тяжёлых библиотек — только `react` и `react-dom`.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # прод-сборка в dist/
```

## Свои вопросы

Всё в одном файле — [src/data/pack.js](src/data/pack.js). Меняй тексты `q` (вопрос)
и `a` (ответ), названия тем и `base` (цена первого вопроса, дальше кратно).
Сейчас там заглушки 5 тем × 5 вопросов.

Сетка строится по данным: добавишь шестую тему или шестой вопрос — поле подстроится само.

## Пароль

Вход по паролю, значение — константа `PASSWORD` в [src/components/Gate.jsx](src/components/Gate.jsx).
Проверка клиентская: пароль попадает в JS-бандл, так что это защита от случайных
посетителей, а не настоящее разграничение доступа. Успешный вход запоминается в localStorage.

## Как играть

Всё с одного устройства: жмёшь клетку → читаешь вопрос вслух → «Показать ответ» →
закрываешь, клетка гаснет. Очки ведущий считает сам. Открытые клетки сохраняются
в localStorage, обновление страницы игру не сбрасывает; кнопка «Сбросить» очищает поле.

Горячие клавиши: `Пробел`/`Enter` — показать ответ, затем закрыть; `Esc` — закрыть.

## Деплой на Vercel

Импортировать репозиторий — Vercel сам определит Vite (build: `npm run build`, output: `dist`).
`vercel.json` уже настроен на SPA-роутинг.
